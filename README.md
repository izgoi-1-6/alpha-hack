# Alfa Credit

Умный кредитный кабинет предпринимателя.

Hackathon MVP for a small-business credit workflow. This repository is being scaffolded; application behavior and service implementations have not been added yet.

## Repository layout

- `backend/` — Spring Boot API service (build system and service details to be decided).
- `frontend/` — analytics interface (framework to be decided).
- `data/` — synthetic companies and test accounts; do not put real customer data here.
- `docs/` — architecture, API, process, data model, scoring, test scenarios, and research.

## Getting started

The project structure is in progress. Setup and run instructions will be added when the service stacks are selected.
