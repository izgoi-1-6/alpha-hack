# Тестовые сценарии

## Стратегия

Каждое правило проверяется на настоящих путях: HTTP-запросы, база данных, байты файлов, браузер. Ожидаемые значения не берутся из проверяемого кода. Тесты считают их сами, через независимые «оракулы» — точные дроби и пошаговый календарь без импорта кода приложения: `backend/tests/*_oracle.py`. Ещё один источник ожиданий — числа этого документа.

| Уровень | Чем | Что проверяет |
|---|---|---|
| Бэкенд, SQLite | `pytest`, изолированная база в памяти на каждый тест | Все правила API, анкеты, скоринга, документов и решений; заглушки и вызовы БКИ; права и `Origin`; повтор команд; файлы |
| Бэкенд, PostgreSQL | тот же набор на базе `*_test` | Плюс гонки на настоящих блокировках строк и частичных индексах: две отправки, два специалиста, одно подтверждение Госуслуг на два запроса |
| Браузер | Playwright в Chrome против запущенного приложения | Экраны клиента и специалиста, семь сквозных сценариев, доступность (цели 44 px, контраст, фокус), отсутствие «демо»-формулировок |
| API-коллекция | папка «Сквозной сценарий» в [postman_collection.json](../api/postman_collection.json) | Весь путь заявки через API от регистрации до перехода в Альфа-Бизнес |
| Docker | `docker compose up --build -d` и `scripts/smoke-docker.sh` через nginx | Сборка образов, миграции, начальные данные, вход и cookie, `Origin`, Госуслуги, заявка, загрузка и скачивание файла, страница перехода |

Каждый браузерный тест регистрирует нового синтетического клиента и добавляет свою компанию. Заявок на компании `client@demo.local` тесты не создают.

## Учётные записи и данные

- Клиент — новый синтетический пользователь (`…@example.test`) или `client@demo.local` (только чтение).
- Чужой клиент — `other@demo.local`.
- Специалист — `officer@demo.local`.
- Пароль начальных записей — `DemoCredit2026!`.
- Компании — 10 синтетических профилей из `data/demo-companies.json`; что показывает каждая, см. в [запуске и показе](../demo.md#синтетические-компании).

## Граничные значения

Каждая граница проверяется с обеих сторон; ожидания считаются целочисленно, а не функциями приложения.

| Что | Значения и ожидание |
|---|---|
| Возраст бизнеса (полные месяцы на 2026-10-24) | с 2026-04-24 — 6 мес. (10 баллов), с 2026-04-25 — 5 (0); с 2024-10-24 — 24 (20), с 2024-10-25 — 23 (10) |

| Просрочка в БКИ | 29 дней — не остановка; 30 — R2 |

```sh
# проверка типов и сборка интерфейса
npm run build --prefix frontend

# браузерные тесты: запущены API, Vite и начальные данные; нужен Chrome
npm run test:e2e --prefix frontend

# проверка каталога и политики
PYTHONPATH=backend backend/.venv/bin/python -m app.products_config check

# описание API и Postman-коллекция совпадают с кодом
backend/.venv/bin/python scripts/export-api-docs.py --check

# стек Docker: сборка и проверка через nginx
docker compose up --build -d && ./scripts/smoke-docker.sh
```

Набор на PostgreSQL отказывается работать с базой, имя которой не оканчивается на `_test`. Браузерные тесты создают новых клиентов в рабочей базе разработки. Вместо Chrome можно взять Chromium: `PLAYWRIGHT_BROWSER_CHANNEL=chromium` после `npx playwright install chromium`. Снимки экрана тестов сохраняются в `frontend/test-results/` (каталог в `.gitignore`).
